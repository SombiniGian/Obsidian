## Convenções de Merge

- Tags de **Casos Up\** devem ser normalizadas via [MAPA_SINONIMOS_TAGS.md](./MAPA_SINONIMOS_TAGS.md) antes de serem adicionadas ao doc final.
- Wikilinks entre casos (ex.: `&lsqb;&lsqb;CASO-001&rsqb;&rsqb;`) devem ser preservados como `relacionados:` em YAML, não como link inline no corpo.
- Conteúdo do caso vira seção do DOCUP correspondente; o título original do caso vira subhead do DOCUP-NNN.
- Conteúdo de **Aulões** (Módulo N) vira seção `## Origem: Aulão Módulo N` no DOCUP destino, preservando a hierarquia interna do aulão como subseções `###`.
- Cada DOCUP destino recebe entrada `fontes.tipo: aulao` apontando para o aulão de origem (data 2026-07-04).
