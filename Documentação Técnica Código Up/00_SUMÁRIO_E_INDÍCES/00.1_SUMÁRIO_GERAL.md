# Sumário Geral — Documentação Técnica Código Up

## 🔗 Mapa de Navegação Entre Documentos

> Este índice é **gerado dinamicamente** pelo plugin Dataview a partir dos YAMLs (`id`, `setor`, `categoria`). Em ambiente Markdown puro (sem Obsidian) o bloco abaixo aparece como código — comportamento esperado.

```dataview
TABLE
  id AS "ID",
  setor AS "Setor",
  categoria AS "Categoria"
FROM "Documentação Técnica Código Up"
WHERE categoria != null AND categoria != "sumarios-indices" AND categoria != "anexos"
SORT categoria ASC, file.name ASC
```

## 🔍 Pesquisa Rápida

Liste os documentos filtrando por tag (exemplos: `#nfe`, `#nfce`, `#pdv`, `#certificado-digital`, `#xml`):

```dataview
LIST
FROM "Documentação Técnica Código Up"
WHERE contains(tags, #nfe) OR contains(tags, #nfce)
```

> **Dica:** substitua `#nfe` por outra tag presente nos documentos para refinar a busca. Tags disponíveis estão no YAML de cada arquivo.
