A ferramenta Relatórios disponível no Apk é extremamente interessante para obter informações diretamente do mobile. Acompanhe o passo a passo para o funcionamento :

1. Relatórios Próprios  
    É necessário ter disponível no sistema relatórios que são próprios para a versão APK. Existem alguns no próprio sistema ou para download no painel da revenda.  
    ![](images/image67.png)

2. Repare nesse relatório que pede para marcar algumas opções que veremos a seguir.  
      
    

3. Gerador de Relatórios  
    No gerador de relatórios procuramos por aqueles que desejamos exportar para o App.

4. Você pode inserir um novo a partir de um arquivo .fr3 e colocá-lo na pasta correta
5. Clique no relatório e marque a opção de Exportar para o App
6. Filtros APP: para configurar as opções é necessário ter conhecimento do relatório, marcando corretamente os filtros utilizados pelo  mesmo.  
    No relatório do painel, por exemplo, já se especifica quais opções devem estar marcadas.  
      
    ![](images/image114.png)  
    

7. Configurar Usuário  
    Precisamos atrelar no cadastro de usuário o vendedor que utilizamos no apk![](images/image90.png)

8. Através do cadastro de usuário incluímos a permissão necessária para acessar o Relatório pelo APK.

9. Clique em Permissões
10. Selecione a empresa e clique em Alterar
11. Clique em Incluir ou pelo atalho F2 e adicione o relatório a lista de permissões
12. Se o usuário for administrador o relatório estará disponível independente de adicionar o relatório nas permissões

![](images/image94.png)  

4. Configurar APP

5. Abra o app, faça login com o vendedor que está atrelado ao usuário que configuramos
6. Em Configurações clique em testar e salvar.  
    ![](images/image57.png)  
    
7. Abra a ferramenta de relatórios  
    ![](images/image39.png)  
    
8. Clique para atualizar, em seguida seus relatórios estarão disponíveis  
    ![](images/image135.png)
