# Tabela TB_TIPO_ATRIBUTO

**Módulo:** Cadastros / Variações
Cadastro de tipos de atributos utilizados para compor variações de produtos (cor, tamanho, voltagem etc.).

## Campos

| Coluna | Tipo | Nulo | Descrição |
|---|---|---|---|
| `TAT_ID` | INTEGER | Não | Identificador único do tipo de atributo. |
| `TAT_DESCRICAO` | VARCHAR(100) | Sim | Descrição do tipo de atributo. |
| `TAT_ID_MELI` | VARCHAR(50) | Sim | ID do tipo de atributo na integração com Mercado Livre. |
